# Qwen3-VL-Embedding + LoRA: GPU-прогоны 27–29 сентября

Статус работ после §11.45–11.46 findings. Все прогоны — на RunPod A100 80GB, адаптер `v2/best`
(не переобучался), сравнение попарное по правилу §11.37: значимо при
|исправлено − сломано| ≥ 2·√(исправлено + сломано).

## Итог

**Production-конфигурация:** Qwen3-VL-Embedding-8B + LoRA v2, эталоны на 1024 визуальных токенах,
**несколько эталонов на вино** (основной + доп. фото каталога `_bottle` / `_front_label`, берётся
максимум схожести), запрос — целый кадр на 2560 токенах, без реранкера и без детекции этикетки.

| Тест | Кадров | top-1 | top-5 |
|---|---:|---:|---:|
| Расширенный тест (наши + организаторов + новые) | 379 | **93.4%** | 98.9% |
| — без 5 кадров-дублей каталога (правило §11.33) | 374 | **94.7%** | — |

Латентность одного запроса на A100: ~0.68 с (эмбеддинг кадра на 2560) + поиск по индексу.

## Что сделано

1. **Индекс достроен до 2102 из 2103 вин.** 19 эталонов добавлены вручную по витринным фото
   (`refs_manual.csv`), без фото остался только «Method Classic Кокур» (в тесте его нет). Гарантированных
   промахов в тесте больше нет: «Олег» и «Розовое золото» находятся.
2. **Тест расширен с 257 до 379 кадров.** Добавлены 122 новых снимка команды из выгрузок
   `wine_real_yolo_20260928*` (новые по SHA-256, в обучение и индекс не попадали, все slug есть в
   каталоге). Исключены 3 кадра Перовских (правка Никиты) и 3 кадра Мезыбь IMG_1653–1655 (на этикетке
   «Каберне Совиньон, Каберне Фран, Мерло 2019» — такой позиции в каталоге нет).
3. **Прогоны:**

| Прогон | Что проверяли | Результат |
|---|---|---|
| hires (257 кадров) | эталоны/запрос 1024 vs 2560 | 1024×2560: 96.1% против 94.6%, 4/1 — шум, но лучший |
| rerank (257) | Qwen3-VL-Reranker-8B по top-5 | 93.4%, 3/10, ~3.4 с/кадр — **отклонён** |
| run1 (379) | вырезка этикетки (ручная рамка / YOLO), несколько эталонов | **несколько эталонов: 93.4%, 14/1 — значимо лучше**; YOLO-вырезка 81.8%, 2/33 — значимо хуже; ручная рамка + кадр 4/0 — в проде рамок нет |
| run2 (379) | 1024 vs 2560 с доп. эталонами; Qwen3-VL-8B-Instruct как «читатель этикетки» | запрос 1024: 2/10 — значимо хуже; 1024+2560: шум; **читатель 82.6% при пороге 0.8, 10/51 — отклонён** |

4. **Проверка на утечку.** Тестовые кадры не совпадают ни с обучением, ни с индексом (SHA-256 и
   dHash). Знакомство адаптера с вином не даёт преимущества: вина, которых не было в обучении LoRA,
   распознаются не хуже (94.1% против 91.8%).

## Почему общая цифра ниже прежних 96%

Качество на старых наборах не изменилось (наши 201 — 96.0%, организаторов 56 — 96.4%). Просадка —
только на 122 новых кадрах (77% с одним эталоном, 86% с несколькими), и она сосредоточена в 9 винах
из 58 из-за серий по 4–8 снимков одной бутылки:

- **Brut d'Or Blanc de Blancs (4 кадра), ZB Frizzante Semi-Dry Rose (1 кадр)** — дубли каталога
  (одно вино под двумя slug), неразрешимы; нужно внести в `field_label_corrections.csv` как exclude;
- **Мезыбь «Каберне Совиньон, Каберне Фран» (4 кадра)** — модель везде отвечает «Мерло», вероятна
  ошибка разметки, нужен аудит по правилам §11.33;
- остальное — соседи по линейке (Бельбек Мускат/Пино Нуар, KAFFA Каберне Фран/Саперави, Собер Баш
  Ркацители/Рислинг, Adagum Odessa Black/Каберне); у 21 из 25 ошибок верное вино в top-5.

Старый тест слегка оптимистичен по двум причинам: его разметку правили после разбора ошибок модели, и
39 кадров в нём — один снимок в двух наборах.

## Что отклонено и почему

- **Реранкеры (Qwen3-VL-Reranker-8B, Qwen3-VL-8B-Instruct без дообучения)** — ломают больше, чем
  чинят, и уверенно ошибаются (у читателя 60% неверных ответов с уверенностью ≥ 0.95).
- **Вырезка этикетки детектором YOLO** — теряет контекст бутылки, значимо хуже целого кадра.
- **Запрос на 1024** при нескольких эталонах — значимо хуже 2560.

   по линейке, запрос на 2560 токенах. Проверка — на тех же 379 кадрах.
