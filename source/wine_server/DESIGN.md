# Серверный сканер и админка

Пользовательский сценарий сканера сохраняет существующий мобильный дизайн: камера/файл → карточка → локальная история. Администратор проверяет истинные метки, а не оценивает красоту каталога. Поэтому четыре вкладки используют уже одобренный интерфейс сравнения: история, фото, папки, границы. Новое визуальное направление не требуется.

Источники фактов: catalog.csv для карточек; базы images/curation_meta для проверенности; scans для исходных предсказаний; annotations для ручных границ. Ни предсказание, ни физическое наличие в images не означает подтверждённую метку. Результат инференса и ручной slug хранятся раздельно. Сервер использует исходные лучшие веса, но другой OCR: версия обозначает это явно.

Основное действие разметки: выбрать последнее название → «Сохранить». Наведение меняет только эталон для просмотра. Назад открывает прежний снимок, в том числе уже размеченный; повторное сохранение меняет его slug с сохранением идентификатора и границ. Мобильная компоновка складывает исходник и поиск последовательно. В редакторе границ используется нормированная система координат ориентированного по EXIF изображения, без привязки к масштабу экрана.

## Дубли фото

Администратор решает конфликт меток одного снимка. Основное действие: сравнить снимок и другие фото из папок → выбрать вино → сохранить. Сохраняем утверждённый бордовый интерфейс, добавляем слева очередь с миниатюрами и счётчиком, в центре исходник, справа кандидатов с независимыми от конфликта фото. На телефоне очередь компактна, затем исходник и карточки; кнопка сохранения стоит после выбора. Удаления файлов нет, ошибочные копии перемещаются в needs_review, доступна отмена. Поиск другого вина и пропуск предотвращают вынужденную ошибочную метку.

Источники: актуальные images/curation_meta для состава групп и количества, catalog.csv для названий и ссылок, sha256/pixel_sha256 для точного совпадения файлов или декодированных пикселей. Сходство дизайна и pHash не выдаются за доказательство одинакового фото. Изображения кандидатов выбираются вне текущей группы; при отсутствии отдельного снимка это явно написано. Все решения принимает пользователь; портал может содержать один снимок у разных вин.
